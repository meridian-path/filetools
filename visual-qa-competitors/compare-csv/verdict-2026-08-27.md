# compare-csv: lineup + squint verdict, 2026-08-27

First lineup/squint check for the spreadsheets folder (Phase 3(c) flagship - also this site's
own highest-traffic individual tool page, per the Compare-CSV Pro paid-feature brief's own
traffic finding).
Screenshots: `verdict-2026-08-27-lineup.png`, `verdict-2026-08-27-squint.png` (this directory).
Produced by `npm run lineup-squint -- dist/data/compare-csv/index.html
visual-qa-competitors/compare-csv`, viewed with the `Read` tool before recording this verdict.

Competitors (real screenshots, non-full-page 1440x900, captured 2026-08-27 via
`scripts/capture-competitor-screenshot.js`): `diffchecker-excel.png` (diffchecker.com's real
Excel/CSV/spreadsheet comparison page), `diffnow-com.png`. Only two, not the doctrine's
aimed-for four to five - three other guessed URLs for real, well-known compare tools
(`diffchecker.com/csv-compare/`, `groupdocs.app/comparison/csv`, `aspose.app/cells/compare`)
turned out to be either real 404s or a blank/failed render on capture, discarded rather than
counted as comparators (a 404 or a firewall/blank page is not a real design to compare
against). Two still clears the harness's own minimum-2 refusal threshold. Both real captures
happened to land mid-promo-modal (Diffchecker's own "get the desktop app" popup, DiffNow's own
changelog popup) - a genuine, common real-world state for an ad-supported tool site, not staged.

## Lineup test: **PASS**

This repo's own tile reads as a single, uncluttered card (a two-file drop-zone, the
spreadsheets-family blue mark, one accent-filled action button) under the shared explorer-window
path bar. Both competitors are visually dominated by a modal dialog sitting over a busy,
multi-color background - Diffchecker's own real product screenshot-in-a-popup, DiffNow's dense
changelog list over a red ad-supported nag banner, a yellow tip banner, and a cluttered top nav.
Neither competitor's own actual tool surface is even the dominant visual element in its own
screenshot; this repo's tile is unmistakably not-a-template by contrast.

## Squint test: **PASS**

Blurred, the page resolves to one dominant shape: the bordered two-file drop-zone card with its
blue mark and teal action button, centered against the lighter background. Heading and deck
text blur to a clearly secondary gray block. One dominant element survives the blur.
