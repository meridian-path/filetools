# merge-pdf: lineup + squint verdict, 2026-08-27

First lineup/squint check for the pdf folder (Phase 3(d) flagship) - the most crowded, most
professionally-produced competitor category checked so far (PDF merge tools are a mature,
heavily-monetized SaaS category). Screenshots: `verdict-2026-08-27-lineup.png`,
`verdict-2026-08-27-squint.png` (this directory). Produced by `npm run lineup-squint --
dist/pdf/merge-pdf/index.html visual-qa-competitors/merge-pdf`, viewed with the `Read` tool
before recording this verdict.

Competitors (real screenshots, non-full-page 1440x900, captured 2026-08-27 via
`scripts/capture-competitor-screenshot.js`, all four succeeded on the first attempt - a rarer
outcome than in the other folders checked so far): `ilovepdf-merge.png`, `pdf2go-merge.png`,
`sejda-merge.png`, `smallpdf-merge.png`. Four, matching the doctrine's own aimed-for range.

## Lineup test: **PASS**

Despite this being real competitive pressure - all four are established, professionally
designed SaaS products, not ad-network templates or dated tools - this repo's own tile still
reads distinctly. ilovepdf and pdf2go both lead with a large full-width red hero band (pdf2go's
also carries a "Add this Chrome extension" browser-permission popup); smallpdf leads with an
equally large purple hero band and a two-column checklist feature list; sejda is calmer but
still runs a visible "How To Merge PDF Files" SEO content block directly below the fold-line
tool itself. All four commit to a branded hero-color-block-plus-marketing-copy shape this
repo's tile does not - the explorer-window path bar plus a plain white bordered drop-zone card
on a neutral background is a genuinely different silhouette from every one of the four, even
though this is the single hardest comparison set checked so far.

## Squint test: **PASS**

Blurred, the page resolves to one dominant shape: the bordered drop-zone card with its pdf-family
red mark and teal action button, centered against the lighter background. Heading and deck text
blur to a clearly secondary gray block. One dominant element survives the blur.
